# ADR-0014：生产发布不设置独立人工审批门禁

**状态：已接受。** 产品长期不要求发布动作先经过独立审批人批准，也不要求提交人与审批人分离；该决定取代 ADR-0012 中有关必需独立审批及双人分离的发布门禁。发布人必须确认语义 Diff、最终配置文本 Diff、目标节点校验结果和发布计划摘要后才能触发发布。候选制品和发布计划仍必须冻结并绑定摘要，目标节点校验、canary、逐节点结果和审计不因移除审批而取消；本 ADR 不代表允许未授权访问或绕过技术门禁。发布权限如何授权仍待明确。

此前方案在单人确认发布与双人审批之间选择了后者，以绑定独立审查责任；现在改为发布人确认 Diff 与计划、但不经过独立审批人，以减少流程角色。相应地不再提供审批人独立复核这一控制；后续需单独确定发布权限和审计规则。
