# ADR-0001：采用单仓库双应用结构

## 状态

已接受

## 决策

项目采用单仓库结构，包含独立的 Go 控制面、`@vben/web-antd` 前端、节点固定发布脚本、示例配置仓库和设计文档。

## 背景

平台同时包含控制面、管理 Web、节点执行脚本和配置规范。它们需要独立构建和部署，但共享领域模型、接口契约、审计语义和版本约定。

## 选择理由

- 便于在同一变更中维护 API、前端页面、配置规则和发布脚本。
- 保持前后端独立构建，不把运行时耦合到同一进程。
- 便于后续按目录拆分流水线或独立仓库，而不改变领域边界。

## 代价

需要维护多套依赖、构建流程和目录级质量门禁；CI 必须避免前端变更触发不必要的后端发布。

## 工程命名

本 ADR 记录的是最初的单仓库方案；代码随后拆分为 `orp-backend/`、`orp-frontend/` 和 `orp-node-agent/` 三个独立项目。
