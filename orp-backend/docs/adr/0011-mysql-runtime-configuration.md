# ADR-0011：MySQL 作为运行时配置与版本来源

## 状态

已接受

## 决策

平台不再以 Git 仓库作为运行配置来源。结构化配置、策略、不可变版本快照和操作审计都存储在 MySQL。

OpenResty Lua 对可动态处理的路由与访问策略加载已发布快照。新增监听端口、原生 `http`/`stream` 块和其他需要重新解析 Nginx 配置的变更，通过节点本机 Unix Socket 调用官方 Control API 执行 `PATCH /1/control/config`。

## 结果

- 每次发布生成内容哈希；相同内容不会创建重复版本。
- 版本快照可供界面比较、回退和节点轮询。
- Unix Socket 不经网络公开，控制面也不直接连接它。
- Lua 动态规则与原生配置重载分别建模，界面必须明确展示生效方式。
