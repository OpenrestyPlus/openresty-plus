# ADR-0002：统一使用 Go 标准库处理 JSON

## 状态

已接受

## 决策

Go 控制面所有 JSON 序列化、反序列化和 API 数据处理统一使用标准库 `encoding/json`。

## 背景

平台处理配置策略、发布任务和审计数据，既需要严格 schema 校验，也需要避免多个 JSON 库带来的行为差异和依赖治理成本。

## 选择理由

- 标准库满足当前 REST DTO 与配置快照的序列化需求，避免引入重复 JSON 依赖。
- 请求与响应使用显式结构体，字段命名和校验规则在 API 层集中维护。
- 便于统一处理 UUID、时间和 JSON 列数据。

## 实施约束

- API 使用显式请求/响应结构体，不直接暴露数据库行模型。
- 对配置输入执行字段校验，并根据接口契约决定未知字段是否拒绝。
